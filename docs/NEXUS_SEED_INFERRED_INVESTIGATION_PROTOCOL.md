## Scope and hypotheses

H-model: an outcome model can be inferred from legitimate source observations,
then frozen and used for investigation on independent target instances.
H-compression: a source-trained tree with greedy fallback retains greedy quality
while reducing full construction-inclusive work versus an equally informed
compiled greedy policy. The alternative is that inference plus exact caching
suffices, with no learned-order advantage. Assess these separately.

This is ordinary supervised outcome inference plus source-trained investigation
reuse. The query rule, ID3 update, compiler and learner do not themselves learn
across families. Even a pass cannot establish learned learning-rule improvement,
unspecified meanings, embodied control, general learning-to-learn or AGI.

Per family32 independent target instances, four/class, IDs1743200000–1743200255.
The evaluator uses class j mod8 within each block. Selectors do not receive j,
the task's class, its answer bank or target outcomes. Task IDs are used only
for deterministic RNG/record provenance, never predictor features. All methods
know the uniform target-class prior and receive exactly the same source data.

Source model reconstructs each class response row, requiring consistency and
coverage; missing/noisy classes invalidate execution (no smoothing or retuning).
This determinism makes exact reconstruction possible; it does not claim
robustness to noise, incomplete coverage or transfer to previously unseen classes.

## Five conditions and shared implementation

1. Original ID3 history tree (depth3,max15 nodes), greedy at abandon leaves.
2. Exact greedy compiled from the source-inferred outcome model.
3. Online exact greedy using that SAME model.
4. Fixed original query order, with that SAME model for belief updates.
5. Random query order, with that SAME model. “no_library” means no learned query
   order, NOT no source outcome model; it is not a source-free learner.

Reuses structure.investigation.learn, investigation_transfer.adapt/LabelOracle,
investigation_hybrid.choose and compiled_greedy.compile_table. Explicit model
parameters preserve historical defaults; never swap global truth tables. No
parallel memory, optimizer, planner, meter or journal. Uniform posterior over
compatible source classes. Stop when identified, at most8 unique reveals;
record belief/prediction snapshots1/2/4/8. These are query-acquisition curves,
not evidence of learned update-rule improvement. Frozen before/after hashes
include the original GRU/RSSM and readout JSON models.
