## Scientific questions and failure rules

1. Does full-signature quotient search preserve every completed primitive-bound
   certificate relative to a separate exhaustive syntax recurrence?
2. Do anonymous operator execution laws reduce completed Tier-1 uniqueness work
   without false certificates? Empirical laws are ordering priors, not proofs.
3. Do source-only self-play, two execution-work heads and independently assessed
   skills improve fixed-horizon acquisition after setup/training costs?
4. Does a source-learned frozen library expand the effective primitive horizon
   under an explicit MDL bound? Merely increasing an integer search limit does
   not answer this question.

The five methods are exhaustive primitive, exact quotient, quotient plus auto
laws, source self-play fixed primitive bound, and evolving MDL horizon. All
completed certificates are independently replayed. False certificates or
arithmetic/provenance mismatches make execution INVALID. Missing strata, cell

## Law certificates and empirical priors

Exhaustive, closed finite carrier execution can certify an operator law.
Pruning additionally verifies that the actual contextual operands belong to

necessary conditions, not undocumented whole-family pruning rules.
