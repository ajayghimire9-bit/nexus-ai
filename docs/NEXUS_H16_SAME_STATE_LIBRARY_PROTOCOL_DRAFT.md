## Question

At a common later simulator state generated by a model-independent
prefix, does reused L0 change the relative selected return of the
frozen H10 multitask recipe versus matched scratch compared with a
fresh library?

This is a mechanistic ranking question. It is not a 200-step control

## Arms, states, libraries

Multitask: exact H10 residual 2×64 recipe. Scratch: same create seed,
target data, target RMS, 20 epochs. Ten model seeds. Four reset
groups per seed. Prefix times t=8 and t=12, motivated by the H14/H15
late-episode interaction, not chosen independently of it.

L0 = `candidate_sequences(library_base + 10s + k)` for both times.
Redraw = `candidate_sequences(redraw_base + 1000s + 10k + t)`.
Both arms receive the same matrix. Sixteen candidates, horizon 16.

Prefix actions are seeded integers from
`prefix_base + 10s + k`, independent of both models.

Restore by `env.reset(seed)` plus the stored prefix only. Never
assign `.state`. Identity failure is `incomplete`.
