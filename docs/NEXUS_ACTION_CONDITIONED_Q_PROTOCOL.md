## Question

Additive action indicators cannot rank first actions differently across states: Q(s,z,a) = f(s,z) + b_a implies a globally constant argmax_a. Matching V's 81-parameter count does not fix that. The 15-coefficient linear Q had the same ranking defect.

**H-action-conditioned-Q:** a compact ridge Q with explicit action×observation interactions, trained only on source first-action-plus-common-zero 64-step returns from **two distinct states per source task**, will raise actual selected first-action 64-step return on fresh development visited states relative to unchanged H=16.

**H-additive-enough:** the compact additive baseline (observation + action dummies, no interactions), fit on the same new source labels, matches or beats the interaction model on that first-action return. That would say interactions were not needed for this decision screen.

**H-no-decision-gain:** better source prediction or source action-identification cannot pass the development screen.

## Estimator and source-only family lock

Registered family **`action_obs`**: observation (3) + one-hot action (3) + action×observation (9) + unpenalized intercept = **16 coefficients**. Ridge λ=**0.1** on the 15 non-intercept weights, source-only mean/scale, floor 1e-8. Scoring context z is **omitted**. Labels are generated by a zero-context continuation, so they do not depend on scoring z; action×context is not identified by these targets.

Comparator **`additive`**: observation (3) + one-hot action (3) + intercept = **7 coefficients**, same ridge, same unique source labels. This is the additive-action baseline, not the unexecuted 81-coefficient polynomial.

Eligible families for the source-only comparison were `action_obs`, `action_obs_z`, and `action_obs_action_z`. Additive is ineligible as the registered selector because it cannot change preferred action across states. Selection metric: decoder-mean leave-one-source-task action identification, then fewer weights, then lower RMSE. Regularization grid {0.1, 1.0, 10.0}. On the historical 24 unique labels, `action_obs` and `action_obs_z` tied on action identification at 0.463; compactness selected `action_obs`, and the ridge grid selected λ=0.1. Action×context was not justified: the same identification rate with extra z coordinates is consistent with fitting z-independent labels. Development outcomes were not inspected. The committed feasibility artifact records the table.

Targets are actual 64-step returns of a forced first action plus 63 zero-context replanning steps. Features use the actual restored observation. Unique (task, state, action) rows are the training units. Repeated scoring contexts are not stacked.

## Distinct source states, not repeated contexts

Historical source collection had **24 unique labels per decoder** (8 tasks × 1 state × 3 actions) even when 6 contexts produced 144 rows. That is too few distinct states for action×observation learning, and repeated contexts are not extra independent targets.

This experiment collects **two independent resets per source task** (16 observations, **48 unique labels** per decoder). Leave-one-task-out training size is 42 unique labels versus 16 weights. That is the smallest increase that both (a) creates state-dependent ranking capacity and (b) keeps the evaluation grid identical to the previous first-action screen.

Fit on the eight source tasks, freeze both Qs to disk, reload before any development environment step.

## Source and evaluation grids

Source: eight `pendulum_context_train` physics, two new resets per task (seeds `6000000+10*t+k`). Continuation seeds `6010000+256*t+64*k`, action-independent. Unique source steps: 10×8×2×3×64 = **30,720**. Disjoint from the 15-coefficient and 81-coefficient seed blocks.

Evaluation: three known development physics, not confirmation. New phase-50 visited states, two visitors per decoder/task (student `(d+t) mod 5` and zero), seeds `6100000+`. Fifty live steps; all five students plus zero score the same 16 candidates. Execute all three first-action+63-zero branches with action-independent seeds.

Selectors see the same candidates and the same three measured first-action returns:

1. **H=16:** argmax of frozen original planner scores.
2. **Sequence-value:** argmax of frozen original score plus survival×V(predicted endpoint). V is not refit.
3. **Additive Q:** argmax over 16 candidates of the 7-coefficient additive readout.
4. **Action-conditioned Q:** argmax over 16 candidates of the 16-coefficient action×observation readout.

Primary return is the measured 64-step common-zero continuation of the selected first action. Not a receding-horizon episode and not a student-policy continuation.

## Primary estimand, aggregation and screen

Decoder n=10, Student-t 95%, df 9. Inside each decoder: average five student seeds, then two visitor groups equally, then three tasks equally.

Primary contrast: action-conditioned minus H=16 first-action 64-return. Pass `action_conditioned_gain` only if the complete grid is valid, mean ≥ 1, and lower bound > 0. Entirely negative interval: `action_conditioned_harm`. Otherwise `action_conditioned_gain_not_established`. Incomplete runs are `incomplete`. Do not change this screen after seeing results.

Secondary, cannot upgrade the primary label: conditioned minus additive; conditioned minus sequence-value; additive minus H=16; source-fit RMSE; development Q RMSE; action agreement; task/visitor intervals. Prediction accuracy cannot pass the screen.

## Decision after evaluation

If `action_conditioned_gain` is assigned, record it and propose a separate fresh-physics / full-episode confirmation. This visited-state first-action screen is not control generalization.

If the complete run does not pass, **close terminal-value score-correction** rather than adding layers, polynomials, or action×context terms. Next work should address receding-horizon policy consistency, action selection and online adaptation under a new protocol.

The unexecuted 81-coefficient additive protocol stays on disk as a negative design result: parameter-count matching without action-conditioned features is not an adequate Q.
