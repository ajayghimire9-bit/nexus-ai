## Loader

`src/nexus/sealed_vault_loader.py`:
* **Token gate.** It refuses unless `NEXUS_SEALED_HARNESS_TOKEN` is set.
* **Integrity checks.** It requires the vault's manifest to be byte-identical to the committed one, and every
  listed file to match its hash.
* **Seed binding.** It binds splits to registry seeds: `group_a` 3001–3010, `group_b` 3011–3020,
  `external_arc_1d_grid` 3021–3030.
* **Entry point.** Only inside the harness, it finds the vault's `load_sealed_split(split_name, seed)` by
  importing manifest-listed `.py` files, and returns
  `SealedTask(train_examples, query_inputs, oracle_fn, hidden_ground_truth_metadata)`.
* **Audit.** Every refusal, verification and load is appended to `runs/experimental/sealed_vault_access.jsonl`.
