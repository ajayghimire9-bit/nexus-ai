## Why old paths stay stable

Protocols, manifests and reproduction scripts contain configuration, source and
artifact paths. Moving hundreds of files would break provenance. We improve
navigation through indexes and status labels instead. Original evidence stays
at its original paths, with negative and incomplete outcomes visible.

Some checkpoint binaries exist only in ignored local directories. A fresh clone
can audit JSON/provenance without them; an explicitly requested checkpoint audit
must fail clearly if a required binary is absent. Do not substitute new weights.

E2.17 stays consumed, H17 blocked, F unrun, and closed splits closed. Research
ledgers and previous results are unchanged.
