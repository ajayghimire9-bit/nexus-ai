# NEXUS Seed — Master Context

## Ultimate goal

Build a compact, adaptive autonomous intelligence system that learns from
experience, plans, transfers useful knowledge, improves its learning methods and
eventually operates across different environments. Learning-to-learn is the
central research objective. General intelligence remains an aspiration, not a
demonstrated capability. No external LLM is required at Seed runtime.

Seed is the active project. Its present testbed is an authored 6×6 object world,
not the final product. Earlier Pendulum, cross-family control, Evolution and PPO
studies are preserved evidence, not an instruction to restart old roadmaps.
Financial applications are outside current scope.

## What exists

The [executable foundation](NEXUS_SEED_FOUNDATION.md) adds bounded compositional
programs, a six-stage supplied curriculum, evidence-linked ingestion and memory
consolidation, source-program abstraction with fresh checks, investigation and
a compact source-count wording decoder. It shares Session/E1 Journal and the
existing skill operators. No new scientific result, frozen-model update or
learning-to-learn claim. The scientific ledger below is unchanged.

The optional executable-world-model path is implemented and its first authored
source test completed frombc57da1. Feature induction passed its narrow screen;
no default promotion or architecture-necessity claim. [Architecture](NEXUS_SEED_EXECUTABLE_WORLD.md),
[results](NEXUS_SEED_EXECUTABLE_WORLD_RESULTS.md). The chat and old core remain available.

A [conversational workspace](NEXUS_SEED_CONVERSATION_WORKSPACE.md) now fronts
the existing four labs. Its deterministic intent adapter, saved dialogue and
inline cards use the SAME Session journal and checked skill library. It adds
no neural learner, scientific result or promoted question-selection policy.

The shared learning-labs engineering layer connects language concepts, list
programs, finite relations and authored world goals to the SAME Session journal
and checked skill catalogue. It can reuse executable programs across compatible
labs, with optional frozen GRU32 representation and source-only rule feedback.
This is a runnable authored prototype, not evidence of useful neural transfer
or improved learning-to-learn. See [guide](NEXUS_SHARED_LEARNING_LABS.md).

- A finite concept learner, typed movement programs, clarification, corrections
  and durable Session/E1 Journal evidence.
- A frozen shared multimodal GRU and RSSM-inspired h32/z8 world model, fixed
  source-bank retrieval, trace decoder and explicit observation-time contract.
- Existing H4/16-candidate latent MPC, known-grid reference and learned one-step
  residual action scoring. Read-only inspection does not advance recurrent state.
- Small reward/meaning adapters; distinct repair, scoped addition and algebraic
  merge; reversible edits and one-use development assessment references.
- A development-scaled surprise gate that requests investigation without
  automatic promotion. Existing epsilon-greedy controller can receive measured
  source-only future-learning gain, forgetting and cost.
- An optional256-parameter rank-four hidden residual, implemented/tested only,
  not enabled or scientifically evaluated.

These paths working does not establish useful continual learning, unrestricted
language understanding, general control, self-evolution or learning-to-learn.
