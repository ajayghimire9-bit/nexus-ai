## Hypothesis and exact intervention

H-residual: retaining a permitted model-specific mean advantage and learning only the context correction improves strategy selection over that mean and direct advantage regression. Alternative: means suffice; the present features or ridge rule cannot reliably predict within-model deviations. A failure is not proof that no useful feature exists, and a pass is not generalization or learning-to-learn.

Define d_i=return(rank_blend)−return(successor_anchor). For a fold-training set T and model key m=(family,bundle), mu_m=mean_{i in T_m}(d_i), calculated as the difference of the two observed controller means. Fit f_theta on targets r_i=d_i−mu_m using the EXISTING AdvantagePredictor/ridge=1, RMS scaling and192 features. Query prediction is **d_hat(x,m)=mu_m+f_theta(x)**. Both mu and r use only fold-training outcomes. No shrinkage coefficient, new feature, intercept, clipping, optimizer or hyperparameter search.

The implementation adds optional known-baseline arguments to the same AdvantagePredictor; baseline0 preserves direct prediction. Baselines are legitimate observed training means, never query-conditioned or predicted rewards. Residuals are derived supervised labels, not newly observed environment feedback. No new learner, memory, proposer, controller, evaluator or resource-meter stack.
