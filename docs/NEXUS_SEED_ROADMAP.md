# Seed milestones S0–S7

These are staged research goals, not already demonstrated capabilities.

- **S0 — Connected local session:** finite English → typed program → authored
  world → measured visible result; private JSON persistence and real GUI.
- **S1 — Teach and clarify:** finite predicate version spaces, disagreement
  questions, corrections and movement transfer across authored layouts. Current
  implementation; measured development outcome belongs in the results report.
- **S2 — Skill teaching:** learn bounded program compositions from demonstrations;
  compare with memorization and fixed program-search baselines. Not implemented.
- **S3 — Representation transfer:** independent object/property schemas and held-out
  semantic templates; measure systematic transfer. Not implemented.
- **S4 — Compact neural guidance:** optional small learned parser/search guidance
  now includes an authored multimodal GRU/RSSM, neural program proposal, learned
  retrieval, value-pruned MPC and local trace decoder. The command-MLP pilot was
  superseded without execution. See NEXUS_SEED_GROUNDED_RESULTS.md: connected
  paths, mixed/weak planning and language; no broad parsing or transfer claim.
- **S5 — Learning-rule selection:** compare question/search update rules under
  equal teaching budgets using existing meta-controller contracts. A functional
  question-policy adapter exists; useful learning-rule improvement is not demonstrated.
- **S6 — Continual cross-domain learning:** durable streams, forgetting and transfer
  tests against reset controls; independent evaluation. Not implemented.
- **S7 — Bounded autonomous assistance:** vetted tools and user-approved actions,
  independently assessed reliability and rollback. Not implemented.

No stage alone establishes general intelligence. Do not skip experimental gates,
reuse closed evaluations as untouched tests, or extend budgets silently.
