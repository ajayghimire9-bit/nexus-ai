# NEXUS Seed charter — S0–S1

This charter is derived from the user's supplied **Seed S0–S1 task**. No
separate charter attachment was present in the supplied attachment directory;
this document is not represented as a verbatim copy of an unavailable charter.

The ambition is compact, local, teachable, data-efficient intelligence that
learns meanings and executable skills from interaction, asks useful questions,
remembers evidence, and eventually improves its learning methods across domains.
AGI is a long-term research aspiration, not an established capability. Historical
Pendulum and other control research remains accessible and scientifically closed.

S0–S1 implements a finite symbolic learner, a declared English command subset,
an authored object world, explicit evidence correction, and a working local GUI.
Colors, shapes, sizes, movement, parsing and predicate grammar are supplied by
code. Labeled examples constrain a version space; they do not teach perception,
arbitrary language, physics or new executable primitives. Explicit predicate
definitions are marked as definitions, not discovery. No unused neural network
is included to imply neural learning.

Reuse the existing Learning Lab, E1 hash-chained Journal and canonical JSON.
Seed concept/evidence/program records are domain-specific additions, not a
parallel evolution framework, research memory stack or meta-controller. Existing
strategy memory and meta-controller interfaces remain available for later vetted
integration; their strategy-feedback semantics do not fit teaching boolean labels.

Local user teaching changes only private session data. It cannot become shell
execution, file permissions, financial actions, research authorization, hidden
evaluation access, or unrestricted source modification. No eval/exec/pickle,
external LLM, embeddings, CDN, telemetry, model download or paid compute is used.
Prior artifacts, frozen checkpoints and closed splits remain unchanged. E2.17
is consumed, H17 blocked, F unrun. Main is not modified or merged.

Measure teaching utility, uncertainty and sample efficiency honestly. An exact
finite-grammar fit, successful GUI demo or development advantage is not general
language understanding, learning-to-learn or AGI. Energy remains unmeasured.
