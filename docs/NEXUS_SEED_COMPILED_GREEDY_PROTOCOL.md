## Question and competing explanations

Does caching the known greedy computation suffice for the efficiency attributed
to source-learned investigation? The alternative is that learned ordering
retains an advantage after source-free exact compilation is fairly charged.
This is an inspected-source audit, NOT fresh validation, confirmation, learning
to learn, or evidence about unsupplied grammars.

## Cost and screen, declared before execution

Primary deterministic audit screen: exact query sequences, posterior states,
snapshots and final predictions versus online greedy for all96 tasks; at least
20% lower construction-inclusive work proxy than learned hybrid; preserved
libraries, checkpoints and complete finite grid. A complete screen failure is
different from an incomplete/invalid execution. No post-result relaxation.

Proxy = candidate-scoring truth-table reads + partition truth-table reads during
construction + runtime scoring reads + posterior-filter checks + policy visits.
Compiled policy pays construction ONCE PER32-task block (three charges); hybrid
pays its own historical source split comparisons per block. Count all actual
compiler candidate-score evaluations, nodes, partition reads, serialized bytes,
runtime policy visits, posterior checks and source observations separately.
Do not call this proxy total FLOPs, total interpreter instructions or wall speed.
Serialization, hashing, loading and final scoring are present in whole-run
wall/CPU time; neither they nor entropy arithmetic are assigned invented proxy
units. Report whole-run runtime/memory and comparative policy-only timings,
including canonical serialized sizes for compiled and learned libraries. The
public64-cell grammar materialization is a common input to every method; its
import/allocation cost is included in host runtime, not added selectively to
one policy's construction proxy. Historical fitting times were measured on a
prior run and are not a hardware-matched construction latency benchmark.
including historical hybrid fit time and newly measured compilation time.
Policy timings are one short observational pass, NOT a robust latency benchmark.

Secondary sensitivity: one shared compiled policy for all96 tasks; report
runtime-only hybrid cost too. Source observations and fit time are amortized
costs but cannot be added numerically to predicate comparisons. No hidden free
precomputation; compiler input is a supplied grammar, itself a substantial prior.

Report per-block/task quality and accuracy/Brier at1/2/4/8; posterior belief
predictions count as assessment operations, not environment interactions.
Pair question differences within each source-library block, then summarize
three block means. Any exploratory t interval uses n3/df2 and is conditional
on this fixed grammar/reused data; compiled/greedy are NOT three independently
learned algorithms. Do not treat96 tasks or3072 final observations as independent
learners. An exact equality assertion is deterministic, not a hypothesis test.
