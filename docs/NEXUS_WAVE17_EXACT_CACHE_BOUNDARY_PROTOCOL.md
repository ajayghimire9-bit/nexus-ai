## Exact masks and two-stage deduplication

For every stored transform mask, obtain exact whole-expression interpreter
outputs on the task observations. Compute coverage only on strict non-default
rows. Independently execute the interpreter again when recording a new mask,
assert membership equivalence and charge that audit. Refresh masks after
clarification changes the observation set, not repeatedly on an unchanged set.

Deduplication first removes exact syntax aliases (including the mathematically
identical INIT/DROP_LAST opcodes) before any execution. Otherwise it evaluates
canonical boundary outputs followed by every current observed input. Never
merge trees just because they agree on reference boundaries. Whole-AST output
memoization prevents repeated execution of an identical typed expression/input.
Signature discovery work for genuinely different ASTs is still charged; there
is no free execution merely because two candidates later collide semantically.

Boundary panel:
`()`, `("a",)`, `("a","b")`, `("a","a")`,
`("a","b","c")`, `("a","b","c","d")`.
Integer tasks use the registered integer reference panel.
Size6–7 wrapper screening applies the exact primitive to already-exact child
outputs only as a necessary proposal test, charging every executed operation.
Surviving original trees still receive full interpreter coverage and assertions.
Peeling, scalar deltas and slicing never supply cached coverage masks.

Order is compressed macro-call syntax size, then structural opcode/arguments,
shared across methods. Expanded primitive execution remains fully charged.
Tier0 proposes base transforms/parity guards; Tier1 adds active macros;
Tier2 adds cold candidates; Tier3 adds the atomic grammar. Any consistent
early-tier guard is certified against the complete primitive guard set too,
preventing a cheap tier from hiding a clarification hypothesis.

## Three owner-requested Phase1 fixes

1. **Lock-only restoration and multi-task tenure.** Probing never restores cold
   ownership. Only references in a verified locked program may reactivate
   macros, resetting age and incrementing use. Promotion/compression cannot
   implicitly restore an unreferenced archived body. Existing MDL ownership
   maintains incremental exact subtree counts. A support event requires at
   least two distinct solved task steps; repeated reviews of one step add no
   support. Supported internal operators receive uses≥2 and an MDL-subtree mark,
   protecting them from age-three once-used eviction. Once-used distractors
   remain evictable. This changes the earlier repeatedly-reviewed-history
   bookkeeping; it is not a claim of unrestricted parametric anti-unification.

2. **Bound observation-gated iteration and duplicate work.** FILTER candidates
   require a token present in a strict input, absent from its output, with at
   least one such output shorter than the input. MAP replacement requires a
   disappearing input token and a newly observed output token. Atomic paths
   do not recursively nest FILTER/MAP at each size. Unary/affix composition
   and wrappers over learned macros remain bounded and shared across methods.
   Exact identity deduplication and output caching happen before scoring.
   Actual signature-discovery and independent-audit work is never hidden.

3. **Wrapped internal-core source curriculum.** Source tasks1/2 in the
   compositional block prepend/append different literals around a shared
   size5 CONCAT(TAIL(x),DROP_LAST(x)) core, with no standalone introduction.
   Task3 REVERSEs that core. Inverting a cached whole-task affix gives only
   the bare core and cannot solve Task3 with one wrapper. Tasks4/5 compose and
   reuse hierarchy. This is an explicitly constructed source mechanism test,
   not proof of cost domination on all tasks; the gate is measured, not assumed.
